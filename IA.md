## Modo usado: Auto

Prompt usado:
El objetivo es crear un app llamada Gorieta. La cual su objetivo es "Facilitar la toma de decisiones al adquirir un vehículo automotor y proporcionar información detallada del vehículo con base en la experiencia de otros usuarios." Dentro de los alcanses que tendra la app es
Mostrar información general de vehículos mediante la API de BlueBook.
Permitir a los usuarios escribir reviews y valoraciones.
Mostrar autos similares según el modelo seleccionado.
Mostrar un Top de vehículos basado en sus reviews.
Módulo de fallas comunes (Pendiente).
Y lo que no abarca son la compra y venta directa de autos ni diagramas ni orientacion tecnica electrica. Se tiene una barra de navegacion con 5 ventanas principales: 1.Inicio 2.Busqueda 3. Agregar contribucion 4. Guardados 5.Perfil. Las APIs a utilizar CarVector.io para obtener informacion sobre los vehiculos y MarketCheck API para obtener el precio del vehiculo. Las reseñas se van a manejar internamente, es decir los usuarios de la app las van a crear. Se piensa usar supabase para almacenar las reviews.
